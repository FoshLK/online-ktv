# 线上 KTV 0.2.0

## 本版新增

- 用户桌面端使用真实服务端房间数据：大厅、创建、加入、退出、成员和在线状态。
- WebSocket 连接使用访问令牌鉴权，客户端不再提交可伪造的用户 ID。
- 曲库查询入口及房主发起播放准备。
- 全员资源就绪屏障、SHA-256 校验、统一未来开始时间和播放序列号。
- 后台桌面端真实运行概览。
- 后台用户查询、停用/恢复、超级管理员角色变更及审计日志。

## 尚未接入

- PostgreSQL、Redis、MinIO 的本机运行实例。
- Tauri 原生资源下载、缓存、音频播放和歌词渲染。
- 受控歌曲导入工作进程。

安装包只包含桌面端，仍需连接运行中的 `online-ktv-server` 才能登录和使用业务功能。
