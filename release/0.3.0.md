# 线上 KTV 0.3.0

本版本完成第一条可实际运行的歌曲资源闭环，并继续只发布 Windows 桌面软件，不提供网页端。

## 新功能

- 内置持久化 PGlite 开发数据库流程，无 Docker/WSL 也能应用 Prisma 迁移和运行服务端。
- 随机开发超级管理员凭据只保存到被 Git 忽略的本机文件。
- 后台桌面端新增曲库管理：上传授权 MP3/WAV 与 LRC、查看资源、发布及下架。
- 服务端新增本地对象存储、文件头/LRC 校验、SHA-256、原子提交、导入任务和管理审计。
- 资源下载接口支持身份认证、HTTP Range、ETag 与当前版本下架保护。
- 用户桌面端新增 Rust 原生缓存下载器，校验音频和歌词后自动发送 `asset:ready`。
- 下载管理界面显示下载、缓存命中、校验成功和失败重试状态。
- 用户端与管理端可在软件内保存 EasyTier 服务端地址，切换服务器时自动隔离登录令牌。
- 增加 EasyTier 安全启动、节点状态脚本与本地服务网络部署说明。

## 验证

- 全仓 TypeScript 类型检查、单元测试和生产构建。
- Rust `cargo check` / `cargo test`。
- 内存生成无版权 WAV+LRC 的真实 API 烟雾测试：管理员登录、上传、数据库发布、完整下载、Range 下载和 SHA-256。
- Windows NSIS 用户端与管理端安装包构建及 SHA-256 清单。

## 已知边界

- 当前对象存储驱动为本机目录；MinIO/S3 生产驱动将在后续版本接入。
- 本版本完成资源缓存和全员就绪上报，音频输出、LRC 滚动及漂移校正仍是下一阶段。
- 网易云、ncmdump、酷狗/KRC 转换等外部工具尚未接入自动任务；仅应处理已获授权的内容。
