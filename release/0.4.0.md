# 线上 KTV 0.4.0

本版本把已完成的歌曲资源闭环接入真正的桌面同步播放器；仍然只发布 Windows 用户端和后台管理端，不提供网页端。

## 新功能

- 用户桌面端可直接播放已校验的本地缓存音频，并显示同步 LRC 歌词。
- 全员就绪后按服务器未来时间统一开播；重连或迟到客户端会自动追赶权威位置。
- 每秒检测播放漂移，小偏差用 0.97–1.03 倍速平滑修正，大偏差直接定位。
- 房主、房间管理员和系统管理员可统一暂停、继续、前后跳转及停止。
- 暂停位置改由服务端时间轴计算，控制命令增加房间/会话身份并使用递增序列号。
- 时钟状态同时显示服务器偏移与网络 RTT；断线重连会重新确认已缓存资源。
- Tauri 本地资源协议仅开放应用缓存中的 `songs/` 目录。
- 增加 LRC、权威位置和漂移策略单元测试，以及 Windows Node 用户信息异常的测试启动兼容层。

## 验证

- 全仓 TypeScript 类型检查、客户端/服务端单元测试和生产构建。
- Rust `cargo check` / `cargo test`。
- 无版权 WAV+LRC 真实 API 烟雾测试及依赖审计。
- Windows NSIS 用户端与管理端安装包构建及 SHA-256 清单。

## 已知边界

- 仍需使用多台真实 Windows 电脑完成扬声器硬件延迟校准和长时间同步验收。
- 在线状态与广播仍为单服务进程；多实例部署前需要接入 Redis adapter。
- 网易云、ncmdump、酷狗/KRC 等外部工具尚未接入自动任务；只应处理已获得下载、转换、缓存和传播授权的内容。
