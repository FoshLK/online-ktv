# 线上 KTV 0.5.0

本版本完成后台监管闭环；仍然只发布 Windows 用户端和后台管理端，不提供网页端。

## 新功能

- 新增独立房间监管页，实时查看房主、在线成员、公告、当前歌曲、播放阶段和资源就绪人数。
- 管理员可填写原因后强制关闭房间或移出成员，服务端再次鉴权并保存操作前后审计快照。
- 强制关闭会结束活动播放并跳过剩余队列；受影响客户端会立即离开实时房间频道。
- 从准备阶段移出成员时自动修正资源就绪屏障；剩余成员全部就绪即可继续统一开播。
- 新增导入任务、播放记录和审计日志分页查询页面，支持按歌曲、房间、管理员或原因检索。
- 概览页接入真实最近导入记录，不再展示任务占位卡片。
- 修复 Windows 开发环境中 Vite 误监听 Rust `target` 目录导致的 `EBUSY`。

## 验证

- 全仓 TypeScript 类型检查、客户端/服务端单元测试和生产构建。
- 使用本地 PGlite 数据库和开发超级管理员实际登录，验证五组后台查询接口。
- Tauri 管理端开发窗口编译并成功启动。
- Rust `cargo check` / `cargo test`、依赖审计及 Windows NSIS 双安装包构建。

## 已知边界

- 自动导入工作进程、失败重试和人工复核尚未实现；当前仍使用授权 MP3/WAV + LRC 手动上传。
- 播放记录尚不支持时间范围筛选和 CSV 导出。
- 审计日志尚未做追加式签名或外部归档。
- 在线状态与广播仍为单服务进程；多实例部署前需要接入 Redis adapter。
- 网易云、ncmdump、酷狗/KRC 等外部工具未接入；只应处理已获得下载、转换、缓存和传播授权的内容。
