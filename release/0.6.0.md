# 线上 KTV 0.6.0

本版本完成 Redis 多实例基础，仍然只发布 Windows 用户端和后台管理端，不提供网页端。

## 新功能

- 在线连接与房间成员状态可写入共享 Redis，并按用户去重统计后台在线人数。
- Socket.IO 接入 Redis Adapter；多个 API 实例可互相广播房间、播放和管理事件。
- 在线 socket 使用 TTL 心跳和过期有序集合；服务进程崩溃后会自动清理陈旧状态。
- 管理员跨实例移出成员或关闭房间时，会同步清理远端实例的房间在线状态。
- 后台桌面端服务健康卡片展示 Redis、在线状态存储和实时广播当前运行模式。
- `/api/health` 增加结构化运行状态；Redis 配置失败时返回 `degraded` 并默认回退到单进程模式。
- 新增 `REDIS_REQUIRED` 强制启动检查以及 Redis 前缀、连接超时和在线 TTL 配置。

## 验证

- Redis 在线状态的内存回退、跨实例共享、用户去重和陈旧 socket 清理单元测试。
- 使用真实 PGlite 启动 API，并以不可连接 Redis 地址验证快速降级和健康接口。
- 全仓 TypeScript 类型检查、单元测试、生产构建、Rust 检查与测试。
- npm 生产依赖审计和 Windows NSIS 双安装包构建。

## 已知边界

- 本版本接入单个 Redis 地址；Sentinel/Cluster、高可用告警和反向代理多实例压力验收仍待完成。
- Redis 在 API 启动阶段失败后不会热切换已降级实例，需要在 Redis 恢复后重启；已成功初始化的运行中连接会自动重连。
- 两个 Windows 安装包尚未配置商业代码签名证书，首次安装可能出现 SmartScreen 提示。
- 自动导入工作进程、失败重试和人工复核尚未实现；当前仍使用授权 MP3/WAV + LRC 手动上传。
- 网易云、ncmdump、酷狗/KRC 等外部工具未接入；只应处理已获得下载、转换、缓存和传播授权的内容。
